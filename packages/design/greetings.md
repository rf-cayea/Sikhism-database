# Greetings

The default screen's greeting ([reading-shell.md](../../docs/requirements/reading-shell.md#the-default-screen)),
one shown at a time, chosen from this list in a shuffled order so that each appears
once before any repeats.

One greeting per line, each a list item. Only the list is read; anything else here is
ignored.
